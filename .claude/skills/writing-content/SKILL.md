# Writing Content

1. **Brief in my head**: audience, goal (what should the reader do/feel), channel, length, tone. Ask only if audience or goal is truly unclear (1 question, with default).
2. **Hebrew by default**, natural Israeli register – not translated-sounding. Gender: plural or both forms when audience is mixed. Numbers/dates Israeli format.
3. **Structure**: hook in the first line → value → proof/detail → one clear call-to-action.
4. **Channel norms**: WhatsApp/SMS ≤ 300 chars, link at end; Instagram/Facebook hook + line breaks + 3–5 hashtags; LinkedIn professional, first 2 lines decide; email subject ≤ 50 chars + preview text; website: headline ≤ 8 words, subhead, benefits as bullets; video script: scene / visual / voice-over columns with seconds.
5. **Give 2–3 variants** for short copy (headline, post, subject line); one polished version for long text.
6. **Rules**: no invented facts, numbers, testimonials or quotes; mark placeholders `[...]`; marketing messages need consent + unsubscribe (Israeli anti-spam law).
7. **Deliver**: short → chat. Long / to share / to edit → Docs (docs skill) or file the user named.
