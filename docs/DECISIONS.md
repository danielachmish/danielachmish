## החלטות עסקיות פתוחות (לא הוכרעו בקוד)
- ספק וחשבון סליקה לכל גוף מקבל; אימות מלא של חוזה PayPlus (ראו PROVIDER_SETUP).
- ערוץ OTP מסחרי (WhatsApp authentication / SMS) – בינתיים אפשר קוד בדוא"ל (D29).
- מסלול WhatsApp והתאמת תזכורות נדרים למדיניות Meta (utility template).
- שירות קבלות.
- מחיר מנוי, מכסת הודעות, תקופת ניסיון, חסד וגישה לאחר ביטול (כרגע מהתצורה).
- ספק דוא"ל לאימות ולאיפוס סיסמה.
- מדיניות שמירה ומחיקה (לא מופעלת מחיקה אוטומטית).
- ספק אחסון/אירוח.
