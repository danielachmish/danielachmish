# Playbook – איך Claude עובד איתך

המטרה: משפט קצר ממך ← תוצר ברמה הכי גבוהה, מהר ובמינימום טוקנים.

## איך זה בנוי
| קובץ | תפקיד | מתי נטען |
|---|---|---|
| `CLAUDE.md` (סעיף Working style) | הפניה קצרה לנוהל | תמיד |
| `.claude/skills/operator` | מסווג כל בקשה, מחליט מה לשאול, אילו כלים, רף איכות | בתחילת כל בקשה |
| `.claude/skills/build-system` | קובע גודל (כלי קטן ← אפליקציה ← מערכת גדולה), אפיון, הרשאות, ארכיטקטורה, שלבים | כל בנייה |
| `.claude/skills/domain-knowledge` | שיטה להפוך למומחה בכל תחום + חבילות מוכנות לתחומים נפוצים | כל בנייה בכל תחום |
| `.claude/skills/research` | נוהל מחקר והשוואה עם מקורות | מחקר |
| `.claude/skills/visual-design` | עיצוב RTL, צבעים, נגישות, בדיקת צילום מסך | כל דבר ויזואלי |
| `.claude/skills/media-production` | סרטונים, אנימציות, תמונות, באנרים דרך קוד | מדיה |

ה-Skills נטענים רק כשצריך, ולכן אפשר להעמיק בלי לשרוף טוקנים בכל שיחה.

## להפוך את זה לגלובלי (בכל פרויקט ובכל שיחה)
1. **העדפות אישיות** – הדבק ב-claude.ai → Settings → Profile → "Personal preferences":
   > אני כותב בקשות קצרות. תפעל כצוות מומחים: סווג את הבקשה (בנייה/מחקר/יצירה/עיצוב/מדיה/נתונים), שאל עד 4 שאלות עם ברירות מחדל רק אם חייב, הבא רעיונות ודרישות של מומחה בתחום מיוזמתך, השתמש בכלים הכי מתאימים (Artifacts, Skills, סוכנים מקבילים, Playwright, ffmpeg), אמת את התוצר לפני מסירה, ותענה קצר. ממשק בעברית RTL, קוד באנגלית. ברירות מחדל: Next.js+TypeScript+PostgreSQL+Prisma, הרשאות לפי תפקידים, ריבוי לקוחות, יומן ביקורת, כסף באגורות.
2. **Skills לחשבון** – העלה כל תיקייה מ-`.claude/skills/` כ-ZIP ב-claude.ai → Settings → Capabilities → Skills (או בקש ממני להכין את ה-ZIP-ים).
3. **פרויקט חדש** – העתק את תיקיית `.claude/skills/` ל-repo החדש; הם נטענים אוטומטית ב-Claude Code.
